# Quake 4 Zombies Mod

## Description
A Call of Duty Zombies-inspired mod for Quake 4. Players survive waves of enemies, earn points, purchase weapons, and use perks to survive longer.

## Installation
1. Place the mod folder in your Quake 4 directory.
2. Launch the mod using the included shortcut.
3. Start the game to play Zombies mode.

## Controls
- **WASD:** Move
- **Mouse:** Look around
- **Left Click:** Shoot
- **R:** Reload
- **E:** Interact
- **Esc:** Pause/Menu

## Features
- Enemy waves
- Points system
- Custom HUD
- Five perks
- Weapon shop
- Enemy loot drops

## Powerups
1. **Max Ammo** — Refills ammunition reserves.
2. **Insta-Kill** — Kills zombies with one damaging hit for 30 seconds.
3. **Double Points** — Doubles zombie kill points for 30 seconds.
4. **Nuke** — Kills all currently living wave zombies and awards 400 points.
5. **Bonus Points** — Instantly awards 500 points.
